## Project Description

This project is a responsive personal portfolio website developed for the WAMD TD-TP 1.

The portfolio presents my academic background, technical skills, projects and professional experience. It is designed to work across desktop, tablet and smartphone screen sizes.

The design follows a creative and minimal visual direction with a dark interface and purple accents.

A web application designed to help users find lawyers.

My role was UI/UX design. I designed the complete website interface in Figma and used external websites for visual inspiration and imagery. The frontend implementation was developed using HTML, CSS and JavaScript.

### Secure Voting System

A secure electronic voting project developed in Python.

I implemented the RSA cryptographic functionality, including encryption and decryption. The system was designed around five entities, including the commissioner.

### Titanic Data Analysis

A data analysis project based on the Titanic dataset.

The project involved analyzing passenger survival data and developing a Streamlit dashboard using Python and Pandas.
